# Aero Dash: Sky High 🚀

A high-octane aerial navigation game built with HTML5 Canvas.

## Features
- 11 Unique Aero Crafts
- 5 Difficulty Levels  
- 7 Power-ups
- Advanced Pilot Ranking System
- Responsive Design

## Technologies
- HTML5 Canvas
- JavaScript (ES6+)
- CSS3 Animations
- Web Audio API
